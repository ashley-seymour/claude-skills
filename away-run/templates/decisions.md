# Away run <date> — decisions taken without the operator

One entry per decision. Take the default the queue row, brief or repo profile
names; with none named, take the reversible option. A decision with neither
stops the row `blocked` instead of landing here.

Format:

- <YYYY-MM-DD HH:MM> · <row id> · **<decision, one line>** · chosen: <path> ·
  default source: <brief/profile/row line, or "reversible option"> ·
  evidence: <command + output line, or file:line> · reverse by: <one step>

Keep each entry to its evidence. Narrative belongs in the morning report.
